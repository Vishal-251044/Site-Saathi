# SITE SAATHI v1.0 · how to install (one page)

*For: site supervisors and testers who receive the APK. (Full guide with Admin Mode comes with v1.1, Day 20.)*

1. Open the **Google Drive link** or the **WhatsApp file** `SITE_SAATHI_v1.0.apk` on the Android phone and tap it.
2. Android asks to allow installing from this app (Drive / WhatsApp / Files): tap **Settings → Allow from this source**, then go back.
3. Tap **Install**. If Google Play Protect warns "unknown developer", tap **More details → Install anyway** (only for the file you got from the project team).
4. Open **SITE SAATHI** → choose मराठी / हिंदी / English.
5. The first time you scan a QR code, allow the **camera**.

- No internet is needed after installing. No account, no login, no personal data.
- Space needed: keep at least 30 MB free (the APK is about 9 MB; installed apps take more).
- To update later: install the new APK over the old one; progress stays.
- Problems: tell the supervisor. This app supports, but does not replace, on-site supervision and safety training.
