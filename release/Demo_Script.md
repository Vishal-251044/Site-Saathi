# SITE SAATHI · demo script (v1.0 ≈ 5 min · v1.1 ≈ 9 min)

Follows PRD §11.6 steps 1–8 (MVP). Steps 9–12 (v1.1 build, Day 20) are below: Ask Saathi, Helmet Check, Supervisor Mode, Admin Mode.
**v1.1 build note:** in `SITE_SAATHI_admin.aia`, Scan is inside **Learn** (step 6: Learn → Scan QR).
Rehearse twice on Day 14, **once fully in airplane mode**.

## Before the demo (10 minutes earlier)
- [ ] Phone charged > 70 %, brightness high, volume up, screen timeout 5 min, Do Not Disturb on
- [ ] App installed (v1.0); Settings → **Reset my progress** → Yes; language set to **मराठी**; text size Normal
- [ ] Printed **SS-MAS-01** poster (and SS-TEST-99, kept separate) on the table
- [ ] Second phone with the same APK as backup; screenshots on the laptop as a last backup
- [ ] Quick Settings open-able with one swipe (airplane mode tile visible)

## Script

| # | Do | Say (short) | Time |
|---|---|---|---|
| 1 | Open the app → splash | "SITE SAATHI is a pocket site trainer for construction workers: scan, see, listen, learn — even without internet." | 0:20 |
| 2 | (Fresh install) choose **मराठी**; it speaks "मराठी निवडा" | "Workers choose Marathi, Hindi or English. Every label comes from one table, so all three always match." | 0:30 |
| 3 | Start learning → module grid → Brick Masonry → lesson | "Six modules; three lessons are ready, the rest say 'coming soon' instead of an empty screen." | 0:30 |
| 4 | Intro → 2–3 steps with Next → tap Listen | "One picture and one or two short sentences per step, plus recorded audio in the worker's language." | 0:45 |
| 5 | **Turn on airplane mode** → continue to the safety page | "No internet now. Everything is inside the app. Safety precautions in red, common mistakes in yellow, before the quiz." | 0:30 |
| 6 | Home → Scan task QR → scan the **SS-MAS-01** poster | "Posters at the work area: scan near the brick wall and the brick masonry lesson opens — still offline." Optional: scan SS-TEST-99 → clear message. | 0:40 |
| 7 | Start quiz → answer one question **wrong** on purpose → explanation → finish → result | "Five quick questions. A wrong answer shows why the right answer is right — reviewed by our civil engineering expert." | 0:50 |
| 8 | Home → My Skills | "Progress and best scores stay on the phone: completed lessons, a bar per module and badges at 4 out of 5." | 0:25 |
| — | Close (v1.0 demo only) | "Built only with free tools — ₹0. Next: Admin Mode so the content team can add lessons from a phone, and AI help by voice." | 0:20 |

## If something goes wrong
| Problem | Do this |
|---|---|
| Scanner does not open / read | Type the code `SS-MAS-01` in the box on the Scan screen (QR-4) |
| Audio not recorded yet | Say "Recorded audio is being added after expert review" and show the step text |
| App closes or freezes | Open the second phone (same state prepared) |
| Ask Saathi slow / no network | Show the offline message — it is a feature (AI is optional) — and the screenshot of an answer |
| Helmet model fails | Play the 30–60 s demo video |
| Phone dead | Show the screenshots / prototype `design/Prototype.html` on the laptop and say it is the design |

**Honesty:** only claim field findings and test results that are written in the testing report.
