# SITE SAATHI v1.1 · how to install (one page)

*For: site supervisors, testers and the content team who receive the APK.*

## Install
1. Open the **Google Drive link** or the **WhatsApp file** `SITE_SAATHI_admin_v1.1.apk` on the Android phone and tap it.
2. Android asks to allow installing from this app (Drive / WhatsApp / Files): tap **Settings → Allow from this source**, then go back.
3. Tap **Install**. If Google Play Protect warns "unknown developer", tap **More details → Install anyway** (only for the file you got from the project team).
4. Open **SITE SAATHI** → choose मराठी / हिंदी / English.
5. Already have v1.0? v1.1 is a separate app (separate App Inventor project): uninstall v1.0 first so only one SITE SAATHI icon shows. Progress from v1.0 is not carried over.

## Permissions (asked only when needed)
| Permission | When | Why |
|---|---|---|
| Camera | Scan QR, Helmet Check | Read the poster code; check the helmet **on the phone** (the photo is not sent) |
| Microphone | Tap the mic in Ask Saathi | Speak a question |
| Internet | Ask Saathi, new lessons, Admin Mode | Lessons, quiz, QR and My Skills work **without** internet |

## Worker and supervisor
- No account and no login for workers.
- **Supervisor mode:** Settings → Supervisor mode → set your own 4-digit PIN. Add only first name + trade. No phone numbers, Aadhaar or photos.
- **Ask Saathi** and **Helmet Check** are AI training aids. They do not replace your supervisor or safety training.

## Content team (Admin Mode)
- Settings → About → tap the **version number 5 times** → Admin login.
- The first Admin creates their own account once with **First setup** (handover guide 04). Writers and Reviewers use the account the Admin gave them **in person**. Passwords are never written in this guide, the app, or a group chat.
- For the demo, use the **test account** only.
- Lessons reach workers only after a reviewer approves and publishes them.

## Problems
Space: keep at least 40 MB free · Helmet Check missing from Home = this phone does not support it (normal) · anything else: tell the supervisor / project team.
